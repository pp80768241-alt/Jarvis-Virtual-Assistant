# Jarvis Virtual Assistant

## About
A Python-based voice assistant inspired by JARVIS.

## Features
- Voice recognition
- Wake word detection
- Text-to-speech
- Open websites
- Play music
- Fetch news
- AI-powered responses

## Technologies
- Python
- SpeechRecognition
- Google Speech Recognition
- gTTS
- Pygame
- OpenAI API
- NewsAPI
